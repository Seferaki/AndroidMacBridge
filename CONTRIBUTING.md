# Contributing

Bug reports and feature ideas are welcome through [GitHub Issues](https://github.com/Seferaki/AndroidMacBridge/issues/new).

When reporting a problem, include the Android model and version, macOS version, app versions, what you expected, and what happened. Remove personal text, files, pairing QR codes, network credentials, and signing keys from screenshots and logs.

For a code change, describe the user-visible effect and how you checked it. Keep credentials, signing files, local SDK paths, generated builds, and personal data out of commits.
